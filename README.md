# THEJAS SHETTY — Portfolio

A living editorial portfolio: warm, minimal, personal, and slightly cinematic.

The original specification requested a dark monochrome design. This implementation intentionally interprets the same structure with a warmer, lighter visual language so the portfolio feels more alive while keeping the professional/personal split.

## Files
- `index.html`
- `style.css`
- `script.js`
- `assets/images/`
- `assets/certificates/`
- `assets/documents/`

## Run
Open `index.html` directly or use VS Code Live Server.

## Add content
Replace bracketed placeholders and add your real images/documents to the asset folders.
